## 🌟 核心特色

- **闪电般启动**：毫秒级加载，没有任何多余弹窗与广告打扰。
- **快捷键驱动**：回车即新建，支持全键盘流畅操作，保持心流不被打断。
- **离线即时存储**：基于 Local-first 架构，断网也能正常记录与勾选。
- **多端轻量同步**：一行同步码即可安全在手机、iPad 与电脑之间同步任务。
