## 🌟 Key Features

1. **"Today" Centered Architecture**: Opens straight to "Today" to eliminate decision fatigue. Focus on what must get done before midnight.
2. **Natural Language Date & Time Parsing**: Type naturally (e.g. `"Buy milk tomorrow 15:00"` or `"明天交周报 重要"`) to automatically set due dates, reminders, and priority tags.
3. **Built-in Focus Tools**:
   - Integrated Pomodoro focus timer with ambient sessions.
   - Monthly calendar view for deadline visibility.
   - Real-time productivity completion stats.
4. **Three Crafted Themes**: Instant switching between **Dark (深色)**, **Light (浅色)**, and **Muted/Elegant (素雅)** palettes.
5. **Local-First & Multi-Device Sync**: Works completely offline. Syncs changes seamlessly across Web, Windows, and Android through unified AILatest accounts.

### 为什么需要 AILatest Todo？
市面上的待办软件大多功能繁琐冗长，配置成本高，反而加重了日常焦虑。

**AILatest Todo 围绕真实的一天设计**：
1. **默认打开「今天」**：不做功能堆砌，把今天真正要推进的要事放在最醒目位置。
2. **自然语言一句话记事**：输入“明天买牛奶；重要 交报告”，系统自动识别日期、时间与重要标签。
3. **侧栏全套效率工具**：无缝集成自定义日历视图、完成度统计看板与专注番茄钟。
4. **Local-first 离线可用**：完全支持断网离线操作，联网后自动与云端安全同步。
5. **多端支持与三套精修主题**：网页即开即用，提供 Windows 桌面版与 Android 移动端支持，自带深色、浅色与素雅主题。
